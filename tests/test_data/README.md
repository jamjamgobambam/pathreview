# PathReview Example Project

![Build Status](https://example.com/badge.svg)
![Coverage](https://example.com/coverage.svg)

This example README documents a polished portfolio project. It provides the
context, setup instructions, and practical workflow a reviewer needs to assess
the work without making assumptions about the local development environment.

## Installation

Install the package and its development dependencies:

```bash
pip install -e ".[dev]"
```

## Usage

Run the application locally, then use the documented endpoints to explore the
project. The example commands below are deliberately small so contributors can
confirm their setup before changing application code.

```bash
make run
```

## Tech Stack

- Python
- FastAPI
- PostgreSQL
- React
- TypeScript
